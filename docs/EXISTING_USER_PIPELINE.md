# Azure Pipelines configuration

`azure-pipelines.yml` defines the automatic Build and Deploy workflow. Configure the repository-scoped Azure Pipelines GitHub App connection in the [ND082-CICD](https://dev.azure.com/nd082-cicd-dj-20261102/ND082-CICD) project.

## Build and automatic deployment

Push and pull-request events on main/master run the Build stage on Microsoft-hosted Ubuntu 24.04 with Python 3.12. `make all` installs dependencies, lints, tests and packages the runtime application. The pipeline publishes `test-results/junit.xml` and `dist/app.zip` as `app-source`.

Deploy depends on successful Build and runs for main/master outside pull requests. It downloads the package from that same run and deploys to the existing Linux App Service through `AzureWebApp@1`. The deployment job uses the `nd082-training` environment.
